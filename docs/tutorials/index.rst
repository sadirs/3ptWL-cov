Tutorials
=========

These tutorials are intentionally compact and runnable on a development
machine.  They demonstrate the current public interfaces without requiring a
large production covariance run.

The main notebook example lives at ``tests/notebooks/example.ipynb`` and saves
its figures under ``tests/notebooks/plots``.  The covariance-matrix tutorial
also renders copies from ``docs/images/notebooks``, plus the R2D2 covariance
plot used to document the paper-data reproduction workflow.
