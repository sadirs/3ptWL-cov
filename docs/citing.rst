Citing and Acknowledgements
===========================

If you use ``wlcov`` in research that leads to a publication, cite the project
and the associated scientific work:

* Sofia Samario-Nava, Alejandro Aviles, and contributors, ``wlcov``.
* Sofia Samario et al., arXiv:2506.19811.

Please also cite upstream methods, libraries, and data products that are
material to your analysis.  The repository acknowledges:

* `GNU Scientific Library`_;
* CLASS;
* Zeno;
* Numerical Recipes.

For reproducibility, include the ``wlcov`` commit hash, compiler version, GSL
version, Python version, and key runtime parameters in any analysis release.
